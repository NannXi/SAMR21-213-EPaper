# Android 更新记录

Android v0.1.4 汇总此前所有应用迭代。配套板端固件为 v0.1.2。

## v0.1.4 · 2026-10-23（汇总版）

- 汇总 v0.1.0 至 v0.1.4 的全部 Android 应用更新，使用 212×104 横向画布，支持选图、旋转、缩放裁切、亮度、对比度、黑白红量化和抖动强度。
- 重做“墨屏”界面，加入固定画布预览、图像调整区、NFC 上传状态和诊断复制；提供原创像素图标。
- 逐步修正初版 NFC 连接与板端仲裁问题；v0.1.2 将邮箱移至未锁定 RF90h..9Fh，使用 CRC 校验分块图像。用户确认 Android v0.1.2 与板端 v0.1.2 上传成功。
- 兼容配套固件 v0.1.2；旧版失败日志、协议测试和验证边界保存在 `docs/` 与 `tests/`。
- v0.1.4 对应 APK versionCode 5；沿用原开发签名，预发布状态。界面和常亮尚待手机验收。
