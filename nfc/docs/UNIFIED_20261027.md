# 图片＋时钟合并版 v0.2.0 · 2026-10-27

## 用法

同一份墨屏App和同一份MCU固件完成两种操作，旧NFC仓库不再维护。

1. 安装v0.2.0 APK，板端升级nfc/firmware合并固件，上电等示例全刷结束。
2. 顶部“推送图片”保留裁切、调色和三色预览；底部上传图片，COMMIT后退出时钟并全刷。
3. 顶部“推送时间”显示手机时钟预览，不需要选图。可选每次全刷（每分钟一次），或局刷＋每1–24小时全刷。
4. 点击底部推送，贴近NFC；识别后获取手机当前Unix时间、时区和毫秒，发CLOCK06命令及设置。
5. 收到确认即可拿开手机，板端首次全刷进入24小时制大字分钟时钟。局刷方案在全刷后加一次数字加深，之后仅变化数字局刷。
6. 改时间或策略再次推送即可；图片与时钟可往返切换。保持主板供电，断电后重新授时。

## 实现与兼容

- 原64字节SRAM邮箱、CRC32、UID/签名/尺寸/锁位识别和RF交接时序保留。无EEPROM写功能，不改锁/熔丝或屏幕电压。
- CLOCK负载16字节，参数、能力回显和兼容字段见[协议](PROTOCOL.md)。旧App图片命令保留；新App的授时功能需要新固件，能力检查在写之前完成。
- 重复CLOCK幂等；图片传输中拒绝抢占授时，活动接图或RF在场推迟定时更新。图片CRC通过的COMMIT才关闭时钟，取消上传保留原模式。
- 采用已实测C款Oswald Regular字形，44×88数字单元、左右约5像素、上下8像素边距，横向212×104。App预览与MCU位图同源；OFL许可保留并打入APK。
- 局刷为60帧擦除＋100帧写黑，约2.4秒；原厂全刷约15秒，周期全刷后额外加深约2.4秒。粉色残影仍可能暂时出现，不把它写成已经完全消除。
- 固件ROM13332字节，RW＋ZI22728字节（含链接配置保留），目标32KiB RAM；构建为Keil ARMCC5 C/ASM。文件名epd_white为历史名，Release另取unified名称。
- 默认J-Link OB下载，保留旧ST-Link可选路径。下载先备份，随后全Flash回读、未写区和辅助区比对，不整片擦除。固件运行不用探针，也不用持续贴着手机。

## 手机验收

- 安装新版后，先在时间页保留局刷＋每1小时全刷，点击推送并贴卡，确认后移开。核对当前HH:mm及下一分钟是否只变化必要数字。
- 改成每次全刷重新推送，核对下一分钟是否全刷；再改回局刷，可选其他小时数。
- 选一张图片上传，核对全刷后不再走时；再推时间，核对重新进入时钟。
- 若报忙或超时，先等当前约15–18秒刷新结束再贴卡；保留App诊断。显示微粉残影、时钟漂移与手机连接问题分别记录。

当前不做晶振校准、掉电保存、自动时区变更、后台传输、低功耗或NFC单独供能。
