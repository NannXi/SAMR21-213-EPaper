# 方向与清晰度记录

日期：2026-10-21。

第一版全小写示例的 MCU 帧缓冲正确，但实物相对壳体倒转了 180°。[当时实物照片](photos/first_demo_upside_down_faint.jpg) 显示红区位于上侧、文字倒置。随后旋转 180°，改为 `Hello World` / `2.13 inch e-Paper`，用户确认“方向正常，仍然偏淡”。

用户对清晰度的描述：“黑字折角处都淡，白色在红底上感觉很泛”。先做完整全白刷新，再刷新新版，用户仍报告偏淡。

程序帧缓冲只有黑、白、红三种离散状态，无灰度、抗锯齿和抖动。已核对实际 MCU RAM 内容、完整 Flash 回读和刷新完成状态。数字预览不证明实物对比度达到同一效果；一次全白清屏也不能排除所有残影或波形适配因素。

目前不能仅凭照片区分屏幕老化、供电负载、温度/波形适配、边缘粒子表现及拍摄因素。后续可用已知良好电源并测量刷新时电压，再与原厂同类黑白文字画面和相同观察条件对照。实际升压波形、屏幕确切 IC、老化程度都还没有仪器验证。

未通过修改未知驱动电压、OTP 或 LUT 进行试错。此版本作为可复现的显示基线保存，清晰度问题保持未解决状态。
