# 硬件与接口

对象：LG Innotek ESL TAG2.13B Rev0.1；PCB 日期 2016-01-20；主控 ATSAMR21G18A。

| 项目 | 实测或来源 |
|---|---|
| DSU DID | `0x10010319` |
| CPUID | `0x410CC601` |
| Flash / SRAM | 256 KiB / 32 KiB |
| 保护状态 | 原板 PROT=0，LOCK=0xFFFF，BOOTPROT=7 |
| 原程序时钟 | 从寄存器推导 48 MHz；未用仪器测频 |
| 自制固件时钟 | OSC8M 8 MHz |
| 屏幕 | WF0213T50CZ16E41e，FPC WFT0213CZ16 LW |
| 分辨率 | 控制器 104×212，横向 212×104 |
| 刷新 | 实测约 15 秒，BUSY 低有效 |

| 屏幕信号 | MCU 引脚 |
|---|---|
| CS | PA23 |
| SDIO / MOSI | PA24；读阶段转 GPIO 输入 |
| SCLK | PA25 |
| BUSY | PA27，低忙 |
| 电源使能 | PA28 |
| D/C | PB22 |
| RESET | PB23 |

原程序使用 SERCOM3 SPI 模式 3，自制固件暂用 GPIO 模拟同一模式。原厂 `0x40` 读取使用 PA24 双向数据，不是简单读取 PA22 MISO。实读 `0x18` 记录为温度相关数据，不能据此识别屏幕 IC。

初始化沿用已捕获的原厂序列：`06 17 17 17`、`04`、温度读取、`00 0F`、`61 68 00 D4`、`50 77`、`10` 第一平面、`13` 第二平面、`12` 刷新；结束后 `50 F7`、`02` 并断屏幕电源。没有测试自定义 LUT 或修改升压参数。

原固件还确认了 NFC I²C 地址 0x55、UID 读取和 NDEF 内容；主控内置 IEEE 802.15.4 射频，不能据此确定原厂使用 Zigbee。UART、ADC 等更多线索见历史 Debug 报告。NFC 传图、无线协议、UART 实际通信和电池低功耗尚未实现或验证。

具体屏幕驱动 IC、偏淡原因、外圈混色区域的确切材料、NFC 传图协议和无线空中协议仍未确定。
