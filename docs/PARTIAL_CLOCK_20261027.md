# 2026-10-27 局刷时钟实验记录

## 当前结论

J-Link OB 可稳定连接 SAMR21，已实际跑通自定义 RAM LUT 差分更新。用户确认只有末位数字变化，效果比整串擦写好很多。仍有更新后暂时的淡粉色残影；精确 IC 修订、红色波形适配和长期稳定性未完全确认。

## 调整过程

| 方案 | 工具测得刷新时间 | 用户观察 |
|---|---|---|
| 原厂三色 OTP | 约 14.97 秒 | 全刷正常、方向正常；部分黑字偏灰 |
| 单段 25 帧 | 约 282 ms | 有反应，旧 0 未消、新 1 不清 |
| 单段 60 帧 | 约 632 ms | 能更新但仍不干净 |
| 120/100 帧两段擦写整个时间 | 约 2.96 秒 | 所有数字一起闪，不符合只动末位目标 |
| 两段、只擦变化数字格 | 约 2.98 秒 | 可以，好很多；局刷位比其他全刷字更黑 |
| 格内背景也擦白，擦白 60 / 写黑 100 | 约 2.38 秒 | 仍有一点淡粉色，但好很多，静置后变淡 |

| 88 像素高字体 | 约 2.36 秒（局刷） | 用户确认大小可以，比较后选择 C 款 Oswald；新字形实物待观察 |

## 红影与黑度差异

用户观察刚刷新后粉色最重，随后减淡，评估需分刚结束与静置后的状态。不能只通过加长单极性脉冲追求黑度。保留原厂三色全刷做周期清理；局刷本身未经过红色专用波形标定。

原厂全刷与自定义局刷的黑度不一致，说明波形可能也是原因，不能只凭现象认定屏幕老化。启动和整点后统一擦写时钟格是改善一致性的实验，尚需实物观察。

## 实现和边界

- PSR 0x3F：黑白 + RAM LUT，0x10 / 0x13 为旧 / 新帧；0x20 为 44 bytes，0x21～0x24 每项 42 bytes。
- VCOM / WW / BB 波形为零；BW / WB 首组分别 0x80 / 0x40。擦除和重画分两次刷新，等待 BUSY，不重叠驱动。
- 不使用前期有花屏风险的 PTL 0x90 窗口；全帧传输加数字格掩码实现光学局部变化。
- 图形与驱动共用数字格坐标和宽高，避免字体变化后仍擦旧尺寸。
- 不修改电压、不写屏 OTP、不改熔丝。预览是逻辑帧，不代表实物颜色。
- 内部 8 MHz 未校准，无掉电 RTC。60,000 ms 定时已验证，不宣称真实时间精度。

## OTP 证据

原始 4096 bytes SHA-256 e96a8870b0c309edd4937ecc81e549b0f99a074b7e55817be194bd19a622b73d，头部 A5 29，0x10..0x12 为 68 00 D4，对应 104×212。

历史分析文本的波形区段列表错误地按每字节滑动生成，不能当成独立温区。本次保存原始 OTP，不采用该错误分段列表。

代码和操作见 [独立分钟时钟工程](../firmware/SAMR21_213_Clock/README.md)。用户观察来自此次调试对话，validation JSON 是实际回读的状态和计数。

## C 字体最终检查

2026-10-27，用户最终选择 C（Oswald），保持大小。固件 9676 bytes，SHA-256 9902ba1a357d986aec5c9a517658b96565845b86d057b6d9231684a79ae87e23。回读与独立工程重编 BIN 相同。12:34→12:35 逻辑帧差异 1884 像素，仅在 x=163..206、y=10..93 的末位内。午夜 23:59→00:00 确认 full_count +1，随后统一数字重画 partial_count +1；自动更新完成，周期配置 60,000 ms、error=0。新字体光学残影没有另行宣称验收。
