## 仍未知或未实现

- 屏幕驱动 IC 精确料号、完整 FPC 针序及升压电路。
- 物理显示偏淡的原因；尚无老化、供电或波形因素的定论。
- NFC 精确芯片型号；兼容行为与成功传输不等于已经确认料号。
- 2.4 GHz 原厂空中协议、配对和加密。
- UART 实际通信、外置 SPI NOR 是否焊接及容量。
- 刷新峰值电流、待机电流、续航、ADC 校准和整机低功耗。
- Keil 原生 FLM 下载与内部在线调试。
- 更大屏幕的电气与波形兼容性。

## 后续工作顺序

1. 在同一光照、温度和供电下比较原厂与自制画面，测量刷新期间电压和电流。
2. 确认电源与测试点连线后，再开展低功耗、ADC 和其他接口实验。
3. 手机界面、NFC 兼容和移场恢复统一在独立 NFC 仓库迭代。
4. 新结论附原始测量或用户观察，保留历史记录；不将静态推导写成实测。
